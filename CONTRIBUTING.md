# Contributing to Tayyar

Thank you for your interest in contributing to **Tayyar Download Manager**!

## How to Contribute

1. **Fork the Repository:** Click "Fork" at [https://github.com/mumenmahbuobeh/tayyar](https://github.com/mumenmahbuobeh/tayyar).
2. **Clone your fork:**
   ```bash
   git clone https://github.com/<your-username>/tayyar.git
   cd tayyar
   ```
3. **Create a branch:**
   ```bash
   git checkout -b feature/amazing-feature
   ```
4. **Make your changes:** Follow standard JavaScript / Node.js best practices.
5. **Run tests:**
   ```bash
   npm test
   ```
6. **Submit a Pull Request:** Open a PR against the `main` branch with a clear description of your changes.

## Bug Reports & Feature Requests

Please open an issue on the [GitHub Issues](https://github.com/mumenmahbuobeh/tayyar/issues) page detailing:
- Operating System & Version (Windows / Linux / macOS / Android)
- Steps to reproduce the issue
- Expected vs actual behavior
- Relevant download URL or file extension
